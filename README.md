# Doce Detalhe — Projeto profissional

Projeto front-end organizado com HTML5 semântico, CSS responsivo e JavaScript modular.

## Estrutura

```text
doce-detalhe-profissional/
├── index.html
├── pages/
│   ├── sobre.html
│   ├── cardapio.html
│   ├── blog.html
│   └── contato.html
└── assets/
    ├── css/style.css
    ├── js/
    │   ├── main.js
    │   ├── menu.js
    │   ├── carousel.js
    │   ├── navigation.js
    │   └── newsletter.js
    └── img/
```

## Como abrir

Use a extensão **Live Server** no VS Code. Como o JavaScript usa módulos ES, abrir por um servidor local evita bloqueios do navegador.

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Clique com o botão direito em `index.html`.
4. Escolha **Open with Live Server**.

## Observações

- O formulário de newsletter é apenas demonstrativo e não salva dados.
- Os links de WhatsApp, redes sociais e informações de contato devem ser substituídos pelos dados reais.
- As páginas internas estão estruturadas e prontas para receber conteúdo.
